## Правило «одне число — одне місце»

Кожне число живе в одному файлі, решта на нього посилаються:

- характеристики й розміри модулів, номінали компонентів — **components.md**;
- номери проводів, GPIO, адреси I2C, коефіцієнти дільників — **connections.md**;
- регістри й таймаути DPS — **dps5015-modbus.md**;
- частоти вибірки, пороги фільтрів, формули — **measurement.md**;
- профілі заряду, пороги стейт-машини — **firmware.md** (таблиця параметрів NVS), concept.md їх лише описує словами;
- формат JSON і REST — **protocol.md**;
- зазори, товщини, допуски друку — **enclosure/requirements.md**.

Закрите питання чи скасований пункт — видаляється, а не позначається виконаним.

## Позначення

| Позначення | Що |
|---|---|
| mDPS, mDIO1–3, mSW1–2, mREL2, mACS1–3, mADC, mMCU, mDC5, mOLED | модулі (components.md) |
| K1, K2 | канали mREL2 — вибір гілки на заряд |
| Bat1 / Bat2 | LiFePO₄ 8S 50 А·год / свинець 24 В 65 А·год |
| B1, B2, CHG, LOAD+, GND, +5V, +3V3 | вузли (connections.md) |
| F1, F2, Fchg, Fout | запобіжники гілок, заряду, виходу |
| P01…, L01… | силові й логічні кола (connections.md) |
| I_B1, I_B2, U_B1, U_B2, U_LOAD, I_LOAD, T1, T2 | вимірювані сигнали |
| SW1_ON, SW2_ON, K1, K2, SENS_PWR, FAULT, BTN, OW, DPS_TX/RX | сигнали GPIO (connections.md) |
| плата A / плата B | logic / bus (plan.md 2.2) |

Одиниці: В, А, А·год, Вт·год, °C, мм; десятковий роздільник — кома в тексті, крапка в коді та JSON.
