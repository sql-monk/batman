## Модульна Ревізія A–D

Це бланк фізичних перевірок, не результати CAD. Спочатку без батарей і DPS, від лабораторного джерела з обмеженням струму; модель mACS та значення VSS підтвердити до подачі живлення.

| Перевірка | Критерій | Результат |
|---|---|---|
| Прозвонка A/B/C/D і CB2–CB6 | немає КЗ; 13 жил за таблицею; CB1 відсутній, CB3 два контакти; CB6 не переплутаний з 3V3 | |
| Чотири кабелі окремих ADS | 16 жил за cable-map; A.J20/J21 до VDD/GND/SCL/SDA, B.J32/J33 до A0…/GND; на B немає I²C | |
| LM2596 → D → A | 5,0 В до встановлення ESP; полярність правильна, USB не створює зворотного живлення | |
| Живлення ADS і датчиків | ADS від A.J20/J21, датчики через C.J24 → B.J25; один LDO, виходи не живляться ззовні | |
| Бюджет 3V3, Wi-Fi + обидва ADS + OLED + датчики | записати піковий струм, просідання і температуру; у межах паспорта фактичного LDO | |
| GPIO33 (J1.8) / Q3 | HIGH/Hi-Z вимикає живлення датчиків, LOW вмикає; перевірити старт і reset; ADC не одержують недопустимих напруг | |
| ADDR і I²C | 0x48, 0x49, OLED 0x3C; заводська перемичка другого ADDR не коротить VDD на GND | |
| Локальні з'єднання ADS | C6/C10 100 нФ біля VDD; J13 A2/A3 GND; обидва ALRT NC; землі двох кабелів надійно зведені | |
| I²C 100 кГц, фронти осцилографом | допустимі рівні та час наростання з усіма підтяжками; без помилок під Wi-Fi | |
| Шість аналогових каналів | 0x48 A0/A1 струми, A2/A3 напруги гілок; 0x49 A0 I_LOAD, A1 U_LOAD; правильний MUX і масштаб | |
| GND кабелів, UART, реле | немає небезпечних струмів повернення; короткі аналогові кабелі не додають недопустимого шуму/зсуву | |
| Порядок підключення | лише при вимкненому живленні; аналогові напруги не подаються на знеструмлені ADS | |
| Посадки й монтаж | гнізда ESP, антена, окремі ізольовані тримачі ADS, 16 кріплень PCB і кабелі не конфліктують | |
