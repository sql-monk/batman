# batman — менеджер двох акумуляторів (LiFePO₄ 8S + свинець 24 В)

Пристрій, що заряджає два акумулятори по черзі від одного DPS5015, віддає їх на спільне навантаження через ідеальні діоди з керованими ключами, і рахує, скільки кожен акумулятор прийняв і віддав.

Усе будується **лише з модулів, що вже є в наявності** (їх повний опис — [docs/components.md](docs/components.md)), плюс дрібні базові компоненти (резистори, діоди, конденсатори) на невеликих однобічних платах ЛУТ.
