# batman — менеджер двох акумуляторів (LiFePO₄ 8S + свинець 24 В)

Пристрій, що заряджає два акумулятори по черзі від одного DPS5015, віддає їх на спільне навантаження через ідеальні діоди з керованими ключами, і рахує, скільки кожен акумулятор прийняв і віддав.

Основа — наявні модулі з [docs/components.md](docs/components.md). Чотири однобічні плати ЛУТ: A з ESP і двома портами I²C для ADS, B з аналоговими входами та фільтрами без I²C, C з розподілом 3,3 В, D з розподілом 5 В. Два окремі ADS1115 одержують аналог із B, живлення/I²C із A. Потрібен ще один ADS1115; C/D розподіляють готове живлення, а не замінюють стабілізатори.
